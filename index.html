01. Product Scope

The Friday Voice Assistant is a highly specialized, interactive desktop voice agent engineered fundamentally upon Python computational logics and paired seamlessly with a responsive HTML5/JavaScript user interface utilizing the Eel library.

Unlike fully cloud-reliant virtual assistants (Alexa, Siri), Friday is tailored to emphasize robust local hardware integration while simultaneously employing a sophisticated locally hosted Large Language Model.

02. Operating Environment

Hardware & Software pre-conditions for optimal 60FPS UI and LLM inference.

Windows OS Baseline

Requires Windows 10/11 Architecture. Non-negotiable for task management paradigms utilizing specific OS registry commands like taskkill /IM.

System RAM Buffer

Requires >8 GB of System RAM to permit simultaneous caching of open-source weights associated with Llama 3.2 inside host RAM/VRAM.

Multi-thread CPU

Essential for maintaining 60 FPS in Javascript concurrently alongside synchronous Python polling loops without Application Not Responding (ANR) lockups.

03. Dual-Process Architecture

To avoid Python's GIL throttling rendering capabilities, the system instantiates independent OS processes employing the multiprocessing library.

Backend Process

target=friday_main, args=(q,)

Operates totally headless. Manages microphone polling, STT via Google, Llama routing, and subprocess execution.

UI Process (Eel)

target=start_ui, args=(q,)

Spawns isolated Webkit renderer. Runs an infinite receiver loop queue.get_nowait() mapping visual mutation intents.

04. Graphical UI

A borderless "HUD" paradigm natively measuring 500x400 pixels, powered by HTML5 Canvas.

  • Spherical Particle View Calculates 3D positions across trigonometric matrices (Cosine rotations, Alpha depth) generating a glowing immersive orb.
  • Active SiriWave Natively parses analyser.getByteFrequencyData updating amplitudes synchronously to user environmental noises.

05. IPC & State Tracking

Inter-Process Communication

Uses multiprocessing.Queue. The logic layer pushes explicit control objects via queue.put().

Format 1: Strings
e.g., "show_listen" -> Native DOM toggle.

Format 2: Dictionaries
{"type": "text_update", "text": result, "hold": time}

Pseudo-State Tracking

State is transient. To prevent user boredom during heavy local LLM queries, Friday implements a mathematical visual hold.

estimated_time = word_count / 1.5

Forces the UI text to hold its CSS BounceInUp state exactly long enough to simulate thinking.

06. NLP & Local LLM Engine

Google STT Matrix

Continuous microphone polling on an infinite while loop. Isolates the specific string "friday" with a strict 2-second timeout.

Local Ollama Endpoint

HTTP POST Operations directly to http://localhost:11434/api/generate, ensuring zero PII data leaks to cloud architectures.

Llama 3.2 Inference

Queries prefixed with ["how", "tell me", "can you", "why"] route directly to llama3.2:latest. Uses Regex to strip Markdown logic for clean TTS output.

07. Desktop Automation

Providing primary productivity capabilities natively, vocal requests trigger subprocess.run implementations handling precise Windows OS commands.

Graceful Teardown: close_process_with_grace handles termination hierarchically, initiating soft kills before enforcing rigorous forced hard kills resolving completely.

08. Network APIs

Enhancing environmental integrations beyond local files.

Media Direct Mapping

Bypasses heavy YouTube API schemas using a static dictionary: {"song": "https://youtu.be/..."} and executes via the python webbrowser library.

NewsAPI Integration

Fetches live JSON payloads routing toward newsapi.org/v2/top-headlines, iterating dynamically across the standard top-level ['articles'] nodes.

09. Non-Functional Constraints

Latency Bounds

Audio detection matrices must cleanly abstract environmental noise natively staying within 500-1200 millisecond time-boxes parsing STT endpoints.

Security Posture

Offline LLM modeling guarantees user prompts natively avoid uploading PII (Personally Identifiable Information) to cloud architectures.

Fault Tolerance

Generic Exception handling (try except KeyError:) bypasses total system crashing constraints, safely falling back to TTS apologies.
